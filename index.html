高级配置（API、代理、并发、倍率、持仓与余额）
建议 3-8。持仓 API + RPC 会增加请求量。
使用每周 week_start / week_end 调用 trades 接口。
官网口径：GraphQL GetPortfolio 的 statistics.positionsValueUsd（同时返回用户名 name）。
默认走同域代理 /api/portfolio；服务端转发到 Predict.fun GraphQL GetPortfolio，返回官网展示的持仓金额(positionsValueUsd)和用户名(name)。
多个路径用英文逗号分隔。默认取 GetPortfolio 的 positionsValueUsd（即官网 Portfolio 卡片显示的持仓金额）。
走 Predict.fun GraphQL pnlTimeseries 最新值。
默认走同域代理 /api/portfolio-pnl；服务端转发到 Predict.fun GraphQL GetAccountPnlTimeseries，返回 pnlUsd。
链上读取 USDT.balanceOf(wallet)。
配置和钱包列表会自动保存在浏览器本地（localStorage），刷新不丢失。钱包列表过大（约 2300 个以上）时不再保存，以免下次打开卡顿。
Predict 持仓接口默认走同域 /api/portfolio 代理，服务端会从 Vercel 环境变量读取凭证并转发到 Predict.fun GraphQL。USDT 可用余额不走 Predict API，而是通过 BSC RPC 调用 ERC-20 balanceOf(address)。
